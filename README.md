## 🚀 Proyectos destacados

### ♻️ EcoXP — Reciclaje inteligente
Sistema de reciclaje gamificado que combina electrónica, sensores RFID y microcontroladores ESP32 para identificar usuarios y validar depósitos de residuos.

**Tecnologías:** ESP32 · Arduino · RFID · Sensores · C++

**Estado:** Prototipo funcional / En desarrollo.

### 🐾 Wildex — Exploración de fauna
Aplicación móvil para descubrir, identificar y registrar animales, con catálogo de especies, fotografías, niveles, desafíos y sistema de recompensas.

**Tecnologías:** HTML · CSS · JavaScript · Supabase · Capacitor

**Estado:** En desarrollo.

### 🤝 CERCA — Gestión de acompañamiento terapéutico
Plataforma orientada a conectar instituciones con acompañantes terapéuticos mediante un sistema de búsqueda, compatibilidad de disponibilidad, asignaciones y reemplazos.

**Tecnologías:** HTML · CSS · JavaScript · Supabase

**Estado:** Demo funcional.

### 🚗 Código Fierro — Diagnóstico automotriz
Herramienta de asistencia para el diagnóstico automotriz mediante códigos OBD2, orientada a facilitar la interpretación de fallas y el registro de vehículos.

**Tecnologías:** Python · Tkinter · Bases de datos

**Estado:** En desarrollo.

### 🛠️ Kench al Rescate — Servicio técnico
Emprendimiento independiente de reparación y mantenimiento de computadoras, celulares, consolas y otros dispositivos electrónicos.

Incluye una plataforma web para gestionar solicitudes de reparación, consultas y seguimiento de servicios.

**Tecnologías:** HTML · CSS · JavaScript · Supabase
